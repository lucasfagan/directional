# Directional

A daily Wordle-style geography game. Set the compass bearing from one city to another — scoring is based on how close you get to the true rhumb-line heading.

**Play at [directional.global](https://directional.global)**

## How it works

- A new city pair every day at midnight UTC
- Drag the compass needle to point from the starting city toward the target city
- One chance per day — no take-backs
- Scoring tiers from Captain Kirk (< 5° off) to Odysseus (45°+)

## Tech

Single self-contained HTML file — vanilla JS, D3 for the result map, no build step.
